# Pesquisas e decisões

Tudo o que foi investigado e não virou código (ou virou, mas tem um porquê que
o código não conta). Um arquivo por assunto: `AAAA-MM-DD-<assunto>.md`.

Antes de pesquisar algo: `grep -ril <palavra> docs/pesquisas/`.

## Modelo

```markdown
# <assunto>

Data: AAAA-MM-DD · Título(s): <OoT3D, SM3DL, genérico> · Commits: <hash>

## Pergunta
O que se queria saber e por quê.

## Fontes
- arquivo:linha / commit / link Azahar ou 3dbrew / comando que reproduz

## Conclusão
O que é verdade, com número quando houver.

## Decisão
O que foi escolhido.

## Alternativas rejeitadas
- <alternativa>: por que não.

## Em aberto
O que não se conseguiu confirmar.
```

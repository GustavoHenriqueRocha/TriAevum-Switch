Mesa 20.1.0 (devkitPro switch-mesa 20.1.0-5: libEGL and libglapi, with the
nouveau gallium driver and the GLSL compiler), statically linked into the Nintendo Switch NRO
for the OpenGL renderer.

Mesa's files carry their own notices; most are MIT. Below: Mesa's license page
(docs/license.html of tag mesa-20.1.0, converted to text), then the BSD-2-Clause
notice of src/util/xxhash.h, which is compiled into libEGL. The C11 threads
emulation (include/c11/threads*.h) is under the Boost Software License 1.0,
which does not require a notice in object code.

Disclaimer

Mesa is a 3-D graphics library with an API which is very similar to
that of OpenGL[1].
To the extent that Mesa utilizes the OpenGL command syntax or state
machine, it is being used with authorization from Silicon Graphics,
Inc.(SGI). However, the author does not possess an OpenGL license
from SGI, and makes no claim that Mesa is in any way a compatible
replacement for OpenGL or associated with SGI. Those who want a
licensed implementation of OpenGL should contact a licensed
vendor.

Please do not refer to the library as MesaGL (for legal
reasons). It's just Mesa or The Mesa 3-D graphics
library.

[1]: OpenGL is a trademark of Silicon Graphics Incorporated.
